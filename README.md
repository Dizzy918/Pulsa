# Pulsa

> Formerly "Tactiq". Bundle IDs and project names are migrated to `com.radoslavslavov.pulsa` / `Pulsa`; the watchOS sources folder (`watchos/TactiqWatch`) and the Android notification channel ID (`tactiq-alerts`, kept so existing installs retain their settings) still carry the old name.

Standalone Android + iOS app for deaf and hard-of-hearing users: it listens to ambient sound, classifies it **on-device**, and turns it into **vibration on the wrist** — so alarms, doorbells, a crying baby or someone calling out never go unnoticed.

Built with Expo (React Native) + TypeScript, with a native **Apple Watch** app (SwiftUI) and universal fallback support for every other band/watch via notification mirroring. (A Kotlin Wear OS app existed through v0.1 — it was removed from the tree but lives on in git history.)

> **Just want to install and use it?** See **[USING_PULSA.md](USING_PULSA.md)** — how to run Pulsa on your iPhone and watch/band with a free Apple ID, no paid developer account.

## How sound reaches the wrist

```
                    ┌──────────────────────────────────────────────┐
 phone microphone ──┤  YAMNet (TFLite, 521 classes, on-device ML)  │
                    │  fallback: rules-based DSP (FFT heuristics)  │
                    └──────────────┬───────────────────────────────┘
                                   │  8 alert categories
                    ┌──────────────┴──────────────┐
                    ▼                             ▼
            WatchConnectivity          High-priority notification
            → Pulsa watchOS app        → mirrored by Huawei Health,
              (haptic sequences)         Mi Fitness, Zepp, Garmin…
```

The watch app also has **standalone mode**: the watch's own microphone + Apple SoundAnalysis on watchOS, so the phone can stay at home.

## Sound categories

| Icon | Category | Urgency | Wrist pattern |
|---|---|---|---|
| ▲ | Alarm / Siren / Smoke detector / Car horn | High | Long triple-plus pulse |
| ◆ | Doorbell / Knock / Phone ringing / Appliance beep | Medium | Double tap |
| ♥ | Baby cry | High | Heartbeat |
| ✦ | Dog bark | Medium | Rapid staccato |
| ◉ | Speech | Low | Gentle double |
| ♪ | Music | Low | Soft double |
| ◈ | Loud noise / Glass / Thunder / Gunshot | Medium | Firm double |
| ◦ | Quiet | — | — |

The ML classifier shows the *concrete* sound ("Smoke detector, smoke alarm · 87%"), while the category drives the vibration pattern. The 521→8 mapping is generated by [`scripts/gen-yamnet-map.js`](scripts/gen-yamnet-map.js) — edit the rules there, then `npm run gen:yamnet-map`.

## Getting started (phone app)

Native modules (`react-native-audio-record`, `react-native-fast-tflite`, `react-native-watch-connectivity`) require a dev build — Expo Go won't work.

```bash
npm install
npm run fetch:model        # downloads assets/models/yamnet.tflite (skippable — app falls back to DSP)
npx pod-install            # iOS only

npm run android            # or: npm run ios
```

> ⚠️ Android builds need JDK 17/21 (Android Studio's bundled JDK works; JDK 25 breaks Gradle 8.10).

On first launch: allow microphone + notifications. On iOS the `audio` background mode keeps detection running with the screen off; on Android keep the app in the foreground while listening.

## Project layout

```
app/                    Expo Router screens (light, minimalist UI — Pulsa brand colors)
components/             Waveform, DetectionCard, WatchMirror, Legend
lib/
  yamnet.ts             TFLite YAMNet wrapper (ML engine)
  yamnetMap.ts          AUTO-GENERATED 521→8 class map
  soundClassifier.ts    category metadata + DSP fallback classifier
  audio.ts              PCM stream → FFT levels + ML/DSP detection
  watchBridge.ts        fan-out: notifications + WatchConnectivity
  notifier.ts           expo-notifications + phone haptic patterns
android/                Expo-generated Android project (package com.radoslavslavov.pulsa)
watchos/TactiqWatch/    Apple Watch app sources (added to Xcode as a watch target)
assets/models/          yamnet.tflite (4.1 MB, fetched by scripts/fetch-model.sh)
scripts/                model fetcher + class-map generator
web-preview/            original Next.js visual mock (reference only)
```

## Engine behavior

- **ML (default)**: YAMNet, 16 kHz mono, 0.975 s window, inference every 500 ms. Status badge shows `LIVE · ML`.
- **DSP (fallback)**: if the model asset is missing or TFLite fails to load — FFT features + tunable scoring rules in `lib/soundClassifier.ts`. Badge shows `LIVE · DSP`.

## Regenerating native projects

`ios/` contains manual additions (the watchOS target once added via Xcode). Avoid `npx expo prebuild --clean` unless you're prepared to re-add the watch target; plain `expo run:android` / `run:ios` are safe.
