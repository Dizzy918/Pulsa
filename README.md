# Pulsa

> Formerly "Tactiq" — internal identifiers (bundle IDs, Xcode/Gradle project names, notification channel IDs) intentionally keep the old name; only user-facing branding changed.

Standalone Android + iOS app for deaf and hard-of-hearing users: it listens to ambient sound, classifies it **on-device**, and turns it into **vibration on the wrist** — so alarms, doorbells, a crying baby or someone calling out never go unnoticed.

Built with Expo (React Native) + TypeScript, with native watch apps for **Apple Watch** (SwiftUI) and **Wear OS** (Kotlin), and universal fallback support for every other band/watch via notification mirroring.

> **Just want to install and use it?** See **[USING_PULSA.md](USING_PULSA.md)** — how to run Pulsa on your iPhone and watch/band with a free Apple ID, no paid developer account.

## How sound reaches the wrist

```
                    ┌──────────────────────────────────────────────┐
 phone microphone ──┤  YAMNet (TFLite, 521 classes, on-device ML)  │
                    │  fallback: rules-based DSP (FFT heuristics)  │
                    └──────────────┬───────────────────────────────┘
                                   │  8 alert categories
          ┌────────────────────────┼─────────────────────────┐
          ▼                        ▼                         ▼
  Wear OS Data Layer      WatchConnectivity          High-priority notification
  → Pulsa Wear app        → Pulsa watchOS app        → mirrored by Huawei Health,
    (custom vibration)      (haptic sequences)         Mi Fitness, Zepp, Garmin…
```

Both watch apps also have **standalone mode**: the watch's own microphone + an on-watch classifier (YAMNet on Wear OS, Apple SoundAnalysis on watchOS), so the phone can stay at home.

## Sound categories

| Icon | Category | Urgency | Wrist pattern |
|---|---|---|---|
| ▲ | Alarm / Siren / Smoke detector / Car horn | High | Long triple-plus pulse |
| ◆ | Doorbell / Knock / Phone ringing / Appliance beep | Medium | Double tap |
| ♥ | Baby cry | High | Heartbeat |
| ✦ | Dog bark | Medium | Rapid staccato |
| ◉ | Speech | Low | Gentle double |
| ♪ | Music | Low | Soft double |
| ◈ | Loud noise / Glass / Thunder / Gunshot | Medium | Firm double |
| ◦ | Quiet | — | — |

The ML classifier shows the *concrete* sound ("Smoke detector, smoke alarm · 87%"), while the category drives the vibration pattern. The 521→8 mapping is generated by [`scripts/gen-yamnet-map.js`](scripts/gen-yamnet-map.js) into both TypeScript (phone) and Kotlin (watch) — edit the rules there, then `npm run gen:yamnet-map`.

## Getting started (phone app)

Native modules (`react-native-audio-record`, `react-native-fast-tflite`, `react-native-watch-connectivity`) require a dev build — Expo Go won't work.

```bash
npm install
npm run fetch:model        # downloads assets/models/yamnet.tflite (skippable — app falls back to DSP)
npx pod-install            # iOS only

npm run android            # or: npm run ios
```

> ⚠️ Android builds need JDK 17/21 (Android Studio's bundled JDK works; JDK 25 breaks Gradle 8.10). See [docs/WEAROS_SETUP.md](docs/WEAROS_SETUP.md).

On first launch: allow microphone + notifications. On Android, listening holds a microphone foreground service so detection keeps running with the screen off; on iOS the `audio` background mode does the same.

## Engine behavior

- **ML (default)**: YAMNet, 16 kHz mono, 0.975 s window, inference every 500 ms. Status badge shows `LIVE · ML`.
- **DSP (fallback)**: if the model asset is missing or TFLite fails to load — FFT features + tunable scoring rules in `lib/soundClassifier.ts`. Badge shows `LIVE · DSP`.

## Regenerating native projects

`android/` and `ios/` contain **manual native customizations** (WearBridge module, ListeningService, the `:wear` module). Do **not** run `npx expo prebuild --clean` — it would wipe them. Plain `expo run:android` / `run:ios` are safe.
